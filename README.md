# Cryptocurrency multi-moment event study

**Review branch: corrected production replication, 12 September 2026.**

Use [`replication-2026-09-03/`](replication-2026-09-03/README.md) for the analysis code, source data, and stored outputs supplied with the September production resupply. The root `code/`, `data/`, `results/`, `paper/` and `springer-submission/` directories predate that correction set and remain historical. They are not the source of record for the revised numbers.

The first-moment difference is +8.69 percentage points (group-wise event bootstrap p=.202). The second-moment curated point multiplier is 3.49, with conditional fixed-path bootstrap p=.389; floored recursive sensitivities reject one-sided and require material positivity repair. The substantive asymmetry is directional, selection-conditional, inference-scheme-sensitive and unresolved. Failure to reject is not evidence that markets treat the categories identically.
